# Focus Timer

A focus timer that counts down in the notch and asks before starting a break.

## Use it

1. In **Setup**, choose a focus length and **Start Focus**.
2. The countdown stays in the notch. Click it to pause, resume or stop.
3. When the session ends, choose **Start Break** for five minutes, **Skip** to keep focusing, or **Done for now**.

Turn off **Ask before starting a break** to start breaks automatically.

This is an example extension. Its source shows an activity, a prompt, settings and stored preferences working together.
